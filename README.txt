1314 碼錶 — iPhone 風格 / 預設時間展示

已保留的需求
• 黑底、細白字大數字、左右圓形按鈕、底部時鐘分頁外觀。
• 底部四個圖示依使用者提供的參考截圖輪廓製成 SVG，包含實心鬧鐘、原參考橘色與選中膠囊比例。
• 配色以最新對照圖左側為準：純深灰底欄、純黑選中背景；橘色保留 Display P3 色彩，並提供轉換後的 sRGB 備援色。
• 依新增的邊框參考，補上細灰色外框與上下亮邊；內部維持已選定的深灰配色。
• 依原生畫面校正數字、按鈕與底部分頁的位置；加入主畫面後以全螢幕高度定位，避免重複計算安全區。
• 少於一小時時主畫面顯示 MM:SS.cc；滿一小時後自動加入小時。字體依數字長度調整，維持置中。
• 初始預設 1314:52:00.00；只有手動按「停止」才結束，結果預設 1314:52:12.31。
• 點底部「計時器」可自訂起始時間與停止後顯示時間，分別設定小時、分鐘、秒及百分秒。設定會儲存在同一瀏覽器。
• 儲存設定會重置本次計時與分圈；關閉設定則不影響本次計時。「還原預設值」須再按儲存才會套用。
• 固定時間展示不是實際時間測量；顯示到設定停止時間前 0.01 秒後，仍會保持計時狀態，等待手動停止。
• 第一圈包含已預載的 1314 小時，後面各圈為兩次分圈間的差值。
• 分圈記錄不會在停止時被重寫；最後一圈補到固定停止時間，各圈總和等於主畫面。
• 同一百分之一秒的連按會忽略，不會產生零秒重複圈。
• 左鍵：計時時分圈，停止後重置；右鍵：開始/停止。停止後再開始會建立新的一次展示並清除上一回分圈。
• 中間兩點可切換數字/指針。底部「計時器」開啟設定；世界時鐘及鬧鐘圖示僅供外觀參考。
• 同瀏覽器重新整理後保留本次狀態；支援離線使用與加入主畫面。
