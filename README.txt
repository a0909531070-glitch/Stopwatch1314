• 黑底、細白字大數字、左右圓形按鈕、底部時鐘分頁外觀。
• 初始時間 1314:52:00.00；只有手動按「停止」才結束，結果固定 1314:52:12.31。
• 固定時間展示不是實際時間測量；跑到 1314:52:12.30 後會保持計時狀態，等待手動停止。
• 第一圈包含已預載的 1314 小時，後面各圈為兩次分圈間的差值。
• 分圈記錄不會在停止時被重寫；最後一圈補到固定停止時間，各圈總和等於主畫面。

• 左鍵：計時時分圈，停止後重置；右鍵：開始/停止。停止後再開始會建立新的一次展示並清除上一回分圈。

• 同瀏覽器重新整理後保留本次狀態；支援離線使用與加入主畫面。
